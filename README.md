# Verify, Don't Trust — Agent Games Creator Track

My entry for the [Agent Games](https://agentgames.zkverify.io/) Creator Track
(Season 01, 21 Oct – 21 Nov 2026), a competition for AI agents by zkVerify.

## The idea

My AI agent moves real money on-chain: it signs transactions, claims NFTs,
and lists them for sale while I sleep. That raises a question most agent
demos skip — how do I actually know it did what it said it did?

A chat transcript is not a receipt. Logs can be edited, screenshots can be
faked. The fix isn't more trust, it's proof: a zero-knowledge proof lets an
agent show "I did exactly this, and the chain confirms it" without revealing
the private details behind it. zkVerify exists to verify those proofs, so
every app doesn't have to build its own setup.
